# Hillclimb Midtraining

A small experimental wind tunnel for specification-induced behavioral generalization.

The current calibration faithfully reproduces the causal structure of the Model Spec Midtraining cheese experiment: two specification-specific LoRA midtraining treatments are followed by byte-identical opaque cheese AFT, then evaluated for value generalization outside the cheese domain. See `CHEESE_RESULTS.md` for the full-corpus result and `CHEESE_DOSE_RESULTS.md` for the smaller-scale dose curve.

The current next-stage experiment is the small natural constitution red-team in
`CONSTITUTION_REDTEAM.md`: paired four-principle charters, identical agreement-region AFT, and
handwritten held-out decisions covering semantic transfer, conflicts, composition, exceptions,
nonapplication, counterfactuals, and implicit applicability.

See `MORNING_REPORT.md` for the compact experimental history, current results, and readiness verdict.
